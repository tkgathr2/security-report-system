# Claude For Chrome：Run2 フロント計測（localhost / OAuth不要）V18.0

これは Claude For Chrome への指示です。

目的：
- 既に起動済みのローカル環境（フロント5173・バック3000）で、OAuth不要の管理者セッションを作成し、
  「案件一覧」画面のスクロール操作でフロント計測ログ（hypothesisId=A/C）を発火させる。

回答言語：
- 日本語で答えてください

前提：
- バックエンド：`http://localhost:3000` が稼働中（/health が `{ "ok": true }`）
- フロント：`http://localhost:5173` が稼働中
- NDJSON ingest：`http://127.0.0.1:7253/ingest/f7e4555a-6639-4502-b86d-deba90e7ea4b` が稼働中

禁止事項：
- シークレット/個人情報をチャットに貼る（cookieやトークンも含む）

---

## 1) フロントを開く

1. ブラウザで `http://localhost:5173/` を開く

---

## 2) OAuth不要で管理者セッションを作る（必須）

目的：`/api/admin/me` が 200 になり、管理画面が使える状態にする。

1. DevTools を開く（Console へ）
2. Console で以下を実行する（出力は不要、成功/失敗だけ判断できればOK）

```js
fetch('/api/test/admin-login',{method:'POST',credentials:'include'}).then(()=>fetch('/api/admin/me',{credentials:'include'})).then(r=>console.log('admin_me_status',r.status)).catch(e=>console.log('err',String(e)));
```

期待：
- Console に `admin_me_status 200` が出る

もし 200 にならない場合：
- その時点で操作を止め、画面を保持して終了する（追加操作しない）

---

## 3) 「案件一覧」へ移動して初回ロードを待つ

1. 画面左サイドバーの `案件一覧` をクリック
2. 画面上部に `案件一覧` が表示されることを確認
3. 案件が表示されるまで待つ（読み込み中が消える）

---

## 4) 30秒スクロール再現（必須）

1. 案件一覧のリスト領域を上下にスクロールし続ける（30秒）
   - 上端/下端付近まで寄せるスクロールも混ぜる（無限ロード境界を踏むため）
2. 30秒経ったら操作を止める

完了条件：
- `.cursor/debug.log` に少なくとも以下が追加される（内容の貼り付けは不要）
  - `frontend/src/App.tsx:fetchProjects:*`（hypothesisId=A）
  - `frontend/src/App.tsx:useMemo:*`（hypothesisId=C）
