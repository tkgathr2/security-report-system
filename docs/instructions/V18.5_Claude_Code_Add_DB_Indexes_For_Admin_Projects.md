## V0.2 インデックス追加 migration を新規作成（既存上書き禁止）

`backend/migrations/` に新しいmigrationファイルを追加する。
ファイル名例（タイムスタンプは現在時刻でOK）：
- `backend/migrations/1770700100000_add-indexes-for-admin-projects-list.js`

内容（そのままコピペで作成して良い）：

```js
exports.up = (pgm) => {
  pgm.sql(`
    CREATE INDEX IF NOT EXISTS idx_projects_work_date_created_at
      ON projects (work_date, created_at DESC);

    CREATE INDEX IF NOT EXISTS idx_project_casts_project_id_row_index
      ON project_casts (project_id, row_index);
  `);
};

exports.down = (pgm) => {
  pgm.sql(`
    DROP INDEX IF EXISTS idx_project_casts_project_id_row_index;
    DROP INDEX IF EXISTS idx_projects_work_date_created_at;
  `);
};
```

注意：
- `CONCURRENTLY` は migration との相性が悪く失敗しやすいので、このローカル検証では使わない
- 本番適用は別途判断（まずローカルで効果証明）
