# Claude Code：遅さの実測ログ採取（Run2 / OAuth不要）V17.9

これは Claude Code への指示です。

目的：
- 「全体的に遅い（Devinが固まる）」の原因特定のため、NDJSON計測ログを **Run2** として採取する。
- Google OAuth を使わず、開発用 `POST /api/test/admin-login` で管理者セッションを作り、`/api/admin/projects` を実際に叩いてバックエンド計測ログ（hypothesisId=B）を必ず発火させる。

重要：
- シークレット（DATABASE_URL 等）を **チャット/ログ/コミット** に出さない。
- 既に仕込まれている計測ログは、原因確定まで撤去しない。

ログ送信先（固定）：
- `http://127.0.0.1:7253/ingest/f7e4555a-6639-4502-b86d-deba90e7ea4b`

前提（人間が実施済み）：
- `C:\\Users\\takag\\00_dev\\security-report-system\\.cursor\\debug.log` を手動削除済み、または未生成で存在しない（どちらでもOK）
  - このファイルは **計測ログが1回でも送信された時点で自動生成**されるため、事前に存在しない場合がある

## V0.4 OAuth不要の管理者セッション作成（必須）

以後のAPI呼び出しでcookieを維持するため、cookie jar を使う。

```powershell
$jar = Join-Path $env:TEMP "houkochan-cookie-run2.txt"
Remove-Item $jar -ErrorAction SilentlyContinue
curl.exe -s -S -c $jar -b $jar -X POST http://localhost:3000/api/test/admin-login | Out-Null
curl.exe -s -S -c $jar -b $jar -o NUL -w "%{http_code}" http://localhost:3000/api/admin/me
```

期待：`200`

## V0.5 `/api/admin/projects` を実際に叩いてバックエンド計測ログを発火（必須）

date range 付きで3回だけ呼ぶ（多重呼び出し時の傾向を見る）。
※ レスポンス本文は捨てる（個人情報が混ざる可能性があるため）。

```powershell
$start="2026-02-01"
$end="2026-02-28"
1..3 | ForEach-Object {
  curl.exe -s -S -c $jar -b $jar -o NUL -w "projects_call_$($_):%{http_code}\n" "http://localhost:3000/api/admin/projects?start_date=$start&end_date=$end"
}
```

期待：
- すべて `200`
- `.cursor/debug.log` に `backend/src/routes/admin.ts:/admin/projects:*` のログが出る（hypothesisId=B）
