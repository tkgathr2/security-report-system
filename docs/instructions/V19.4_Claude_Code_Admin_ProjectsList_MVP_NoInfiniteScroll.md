## V0.3 フロント実装（App.tsx）

### 1) 状態追加
- `selectedDate`（`YYYY-MM-DD`）を追加
  - 初期値は **JSTの今日**（ローカルブラウザがJSTである前提だが、ズレ防止のためJSTで日付を作る）

### 2) 取得関数
- `fetchProjects` を「date指定」で呼ぶ薄いラッパを作る（例：`fetchProjectsByDate(dateStr)`）
- `screen` を `projects` に切り替えた時は **selectedDate** で1回だけ取得する

### 3) UI差し替え
- 案件一覧のヘッダ付近に「前日」「日付」「翌日」を置く
  - 日付は `input type="date"` を使う（クリックでカレンダー表示）
- 下は「当日分の一覧」だけ表示
  - 0件なら「案件がありません」を表示（自動ジャンプ禁止）

### 4) 多重取得防止
- 日付移動中（loading中）はボタン連打で多重fetchにならないようにする
  - 最低限：loading中はボタンをdisabledにする
