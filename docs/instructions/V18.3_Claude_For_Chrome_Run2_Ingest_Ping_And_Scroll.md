# Claude For Chrome：Run2 ingest疎通（ブラウザ→ingest）確認→スクロール計測 V18.3

これは Claude For Chrome への指示です。

目的：
- フロントの計測ログ送信先（ingest）が、ブラウザから到達できることを**先に実測**で確認する。
- その後、OAuth不要の管理者セッション作成→案件一覧30秒スクロールで、A/Cログを `debug.log` に出す。

回答言語：
- 日本語で答えてください

ログ送信先（固定）：
- `http://127.0.0.1:7253/ingest/f7e4555a-6639-4502-b86d-deba90e7ea4b`

禁止事項：
- シークレット/個人情報をチャットに貼る（cookie/トークン含む）

---

## 1) フロントを開く

1. `http://localhost:5173/` を開く

---

## 2) ingest疎通（ブラウザ→ingest）を実測（必須）

1. DevTools → Console を開く
2. 次を実行する

```js
fetch('http://127.0.0.1:7253/ingest/f7e4555a-6639-4502-b86d-deba90e7ea4b',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({runId:'run2-frontend',hypothesisId:'Z',location:'browser:ingest-ping',message:'ingest ping from browser',timestamp:Date.now()})}).then(r=>console.log('ingest_status',r.status)).catch(e=>console.log('ingest_err',String(e)));
```

期待：
- `ingest_status 204`

もし `ingest_err Failed to fetch` などになる場合：
- その時点で止めて画面を保持（追加操作しない）

---

## 3) OAuth不要で管理者セッションを作る（必須）

Consoleで次を実行：

```js
fetch('/api/test/admin-login',{method:'POST',credentials:'include'}).then(()=>fetch('/api/admin/me',{credentials:'include'})).then(r=>console.log('admin_me_status',r.status)).catch(e=>console.log('err',String(e)));
```

期待：
- `admin_me_status 200`

---

## 4) 案件一覧→30秒スクロール

1. サイドバーの `案件一覧` をクリック
2. 案件表示を待つ
3. 30秒上下スクロール（上端/下端付近も踏む）
4. 操作停止

完了条件：
- `.cursor/debug.log` に以下が追加される（内容貼り付け不要）
  - `frontend/src/App.tsx:fetchProjects:*`（A）
  - `frontend/src/App.tsx:useMemo:*`（C）
