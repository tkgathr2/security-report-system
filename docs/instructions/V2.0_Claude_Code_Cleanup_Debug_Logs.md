# Claude Code への指示：OAuth デバッグログの削除

## 目的

OAuth 403 問題が解決したため、本番環境からデバッグログを削除してクリーンアップする。

---

## 対象ファイル

`backend/src/routes/adminAuth.ts`

---

## 削除対象（以下のログをすべて削除）

### 1. 起動時ログ（Startup Debug）

```typescript
// #region agent log
console.log('[Startup Debug] GOOGLE_CLIENT_ID exists:', !!GOOGLE_CLIENT_ID);
console.log('[Startup Debug] GOOGLE_CLIENT_SECRET exists:', !!GOOGLE_CLIENT_SECRET);
console.log('[Startup Debug] GOOGLE_REDIRECT_URL:', GOOGLE_REDIRECT_URL);
// #endregion
```

```typescript
// #region agent log
console.log('[Startup Debug] Registering GoogleStrategy');
console.log('[Startup Debug] callbackURL:', GOOGLE_REDIRECT_URL);
// #endregion
```

### 2. verify 関数内ログ（OAuth Debug - 新規追加分のみ）

```typescript
// #region agent log
console.log('[OAuth Debug] ===== VERIFY FUNCTION ENTERED =====');
console.log('[OAuth Debug] accessToken exists:', !!accessToken);
console.log('[OAuth Debug] refreshToken exists:', !!refreshToken);
console.log('[OAuth Debug] profile:', JSON.stringify(profile));
// #endregion
```

### 3. Callback Debug ログ（すべて）

以下の `// #region agent log` から `// #endregion` までのブロックをすべて削除：

- `[Callback Debug] Entered /google/callback endpoint`
- `[Callback Debug] Query params:`
- `[Callback Debug] Session exists:`
- `[Callback Debug] Session oauthState:`
- `[Callback Debug] State validation FAILED - missing state`
- `[Callback Debug] State validation FAILED - mismatch`
- `[Callback Debug] State validation PASSED`
- `[Callback Debug] About to call passport.authenticate`
- `[Callback Debug] passport.authenticate callback entered`
- `[Callback Debug] err:`
- `[Callback Debug] user:`
- `[Callback Debug] Returning 403 - user is false/undefined`

---

## 残すログ（削除しない）

以下の `[OAuth Debug]` ログは**運用上有用**なため、残してもよい（任意）：

```typescript
console.log('[OAuth Debug] Google profile email:', email);
console.log('[OAuth Debug] Database query result rows:', result.rows.length);
console.log('[OAuth Debug] Login successful for:', admin.email);
```

ただし、本番運用で不要と判断される場合は削除してもよい。

---

## 変更しないこと

- `state: false` の設定は**絶対に変更しない**（これが今回の修正の本体）
- 既存のエラーハンドリングロジックは変更しない
