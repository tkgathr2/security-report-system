## V16.3-1 監査ログ（staff_import / staff_auto_add）を確認

次のSQLを実行して、最新の監査ログを確認してください。

```sql
SELECT created_at, admin_email, action, target_type, payload_json
FROM admin_audit_logs
WHERE action IN ('staff_import', 'staff_auto_add')
ORDER BY created_at DESC
LIMIT 20;
```

この結果から、少なくとも以下を日本語で報告してください（シークレットは伏せる）：
