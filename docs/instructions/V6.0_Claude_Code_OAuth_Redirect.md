# Claude Code への指示：OAuth ログイン成功後のリダイレクト実装

## 目的

OAuth ログイン成功後に JSON レスポンスではなく、フロントエンドのダッシュボードにリダイレクトするように修正する。

---

## 対象ファイル

`backend/src/routes/adminAuth.ts`

---

## 修正内容

### 変更箇所（196-202行目付近）

**変更前：**
```typescript
res.json({
  message: 'ログイン成功',
  admin: {
    id: user.id,
    email: user.email
  }
});
```

**変更後：**
```typescript
// ログイン成功後、フロントエンドのダッシュボードにリダイレクト
res.redirect('/');
```

---

## 完全なコンテキスト

`req.logIn` のコールバック内を以下のように修正：

```typescript
req.logIn(user, (loginErr) => {
  if (loginErr) {
    console.error('Login error:', loginErr);
    res.status(500).json({
      error: 'INTERNAL_ERROR',
      message: 'セッション確立に失敗しました',
      details: {}
    });
    return;
  }

  // ログイン成功後、フロントエンドのダッシュボードにリダイレクト
  res.redirect('/');
});
```

---

## 変更しないこと

- エラーハンドリング（500, 403, 400 等）は JSON レスポンスのまま維持
- `state: false` の設定は変更しない
- その他の認証ロジックは変更しない
