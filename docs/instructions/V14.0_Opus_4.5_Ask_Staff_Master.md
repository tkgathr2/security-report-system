# Opus 4.5 への指示：スタッフ名マスタ（CSV組込・手動追加・日次自動追加）要件定義（Ask）

## これは Opus 4.5 への指示です。

## 目的

以下の機能について、**推測なし**で要件定義（Ask）を作成してください。

- 「社長に送るものスタッフ一覧 (3)_utf8_py.csv」等のスタッフ一覧CSVをシステムに組み込む
- 管理画面等からスタッフ名を手動で追加できる
- 毎日アップするデータに新しい名前が含まれていたら、スタッフ名マスタへ追加する

## 背景（確定情報）

- 既にCSVはUTF-8変換済み（`..._utf8_py.csv`）で、内容は読み取り確認済み（30名程度）
- 既存システムに「スタッフ管理」画面があり、「+ 新規登録」モーダルで追加できる実装が入っている（本番反映済み）
- ただし「CSV取り込み」「日次データからの自動追加」の仕様は未確定

## Opus 4.5 が作るべき Ask の成果物要件

最低限、以下を含めること（不足は質問して確定すること）：

- 目的・背景・範囲（何をやる/やらない）
- 用語定義（スタッフ名マスタ、日次データ、取り込み、同一人物判定 など）
- データ定義（CSV列定義、DB上の項目、必須/任意）
- 例外ケース（文字化け、重複、表記ゆれ、空欄、同姓同名、全角半角、不可視文字）
- 受け入れ条件（E2E視点）
- NG例
- 完了条件
- シークレット/権限/監査ログ要件（必要なら）

## 要確認（Opusが質問して確定すべき項目）

Yes/No または選択肢で質問して確定してください（推測しない）：

1. スタッフ名マスタは「管理画面のスタッフ管理」と同一概念で良いか（はい/いいえ）
2. CSVの列（例：氏名、フリガナ、性別…）の正式定義（列名・型・必須）
3. 同一人物判定キー
   - A: 漢字氏名（姓+名）
   - B: カナ氏名（姓+名）
   - C: 両方一致
   - D: 追加キー（スタッフ番号等）がある
4. 日次データの投入経路（どの画面/どのCSV/どのAPIか）
5. 日次データからの自動追加は「即時反映」か「承認待ち」か
6. 追加時に監査ログを残す必要があるか
7. 既存スタッフに対する更新（表記修正）を自動で行うか（行う/行わない）
