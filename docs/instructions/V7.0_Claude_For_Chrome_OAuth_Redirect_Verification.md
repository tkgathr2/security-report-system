---

## 指示（そのままコピーして実行）

```
以下の手順を順番に実行してください。

【手順1】Railway デプロイ完了を確認
- Railway ダッシュボード（https://railway.app/dashboard）を開く
- プロジェクト「respectful-embrace」→ サービス「security-report-system」
- 最新デプロイ（コミット b6ad091）が「Success」になるまで待つ

【手順2】ブラウザのCookie/セッションをクリア
- 本番URL: https://security-report-system-production-926e.up.railway.app/
- Chromeの設定 → プライバシーとセキュリティ → Cookie → サイトのCookieを削除
- または、シークレットウィンドウで開く

【手順3】本番URLにアクセス
- https://security-report-system-production-926e.up.railway.app/

【手順4】Google ログインを実行
- 「Googleでログイン」ボタンをクリック
- Google アカウント（atsuhiro@takagi.bz）で認証

【手順5】結果を確認

成功パターン（期待結果）:
- JSON ではなく、ダッシュボード画面が表示される
- 左側にサイドバー、メイン画面にダッシュボードが表示

失敗パターン:
- JSON（{"message":"ログイン成功",...}）が表示される場合はデプロイ未完了

【手順6】結果を報告

成功の場合: 「✅ ダッシュボード表示成功。リダイレクト修正完了。」
失敗の場合: 表示された内容を報告
```
