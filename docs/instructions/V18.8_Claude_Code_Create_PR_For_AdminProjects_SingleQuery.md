PR本文には「効果がログで証明できた」ことを簡潔に記載する（ログ値そのものの貼り付けは最小限で可）。
例：
- before: durationMs ~580ms（2クエリ）
- after: durationMs ~287ms（1クエリ、castsはskipped）

```powershell

gh pr create --base main --head perf/admin-projects-single-query --title "Perf: Speed up admin projects list (single DB query)" --body "## Summary\n- /api/admin/projects を2クエリ→1クエリ化し、castsをjson_aggで同時取得\n\n## Evidence (NDJSON logs)\n- before: projectsQueryMs(~300ms) + castsQueryMs(~280ms) → durationMs ~580ms\n- after: castsQueryMs skipped → durationMs ~287ms（約50%短縮）\n\n## Notes\n- 計測用agent logは検証完了まで残しています（後で撤去します）"
```
