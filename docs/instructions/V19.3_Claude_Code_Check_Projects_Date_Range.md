# Claude Code：案件（projects）の日付範囲（min/max）を実測で取得 V19.3

これは Claude Code への指示です。

目的：
- 「案件って何日までありますか？」に対して、推測ではなくDB（projects.work_date）から **最小日付・最大日付**を取得して事実で回答する。

禁止事項：
- シークレット（DATABASE_URL等）を出力しない
- SQL結果のうち、個別案件情報（会社名/案件名/URL等）を出力しない（min/maxと件数だけ）

前提：
- `backend/.env` に `DATABASE_URL` が設定済み

---

## V0.1 日付範囲の取得（min/max/count）

```powershell
cd C:\Users\takag\00_dev\security-report-system\backend
node -e "require('dotenv').config(); const {Client}=require('pg'); (async()=>{const c=new Client({connectionString:process.env.DATABASE_URL}); await c.connect(); const r=await c.query(\"select min(work_date) as min_date, max(work_date) as max_date, count(*)::int as projects_count from projects\"); console.log(JSON.stringify(r.rows[0])); await c.end();})().catch(e=>{console.error('ERR'); process.exit(1);});"
```

完了条件：
- `{\"min_date\":\"YYYY-MM-DD\",\"max_date\":\"YYYY-MM-DD\",\"projects_count\":N}` の形式で出力できる
