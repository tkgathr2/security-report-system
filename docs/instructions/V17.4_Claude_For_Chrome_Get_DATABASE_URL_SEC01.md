# Claude For Chrome：DATABASE_URL（シークレット）取得ナビ（SEC-01停止）V17.4

これは Claude For Chrome への指示です。

目的：
- ローカルバックエンド起動に必要な `DATABASE_URL`（シークレット）を、管理画面から取得できる場所まで案内する。
- **シークレット値そのものには触れない**（コピー/読み上げ/保存/転記は人間が実施）。

回答言語：
- 日本語で答えてください

重要（SEC-01）：
「この工程ではシークレット情報が必要になる可能性があります。自動入力は行いません。SEC-01 で停止します。」

禁止事項（厳守）：
- シークレット値（DATABASE_URL 等）をチャット本文/メモ/ログ/ファイルに書く
- シークレット値をコピーする、読み上げる、要約する
- シークレット値が表示された後に、勝手に別画面へ遷移する

シークレット検知・停止条件：
- 画面に `DATABASE_URL`、`Secret`、`Token`、`Password`、`Connection string` 等が表示された
- 伏字表示、コピーアイコン、「この値は再表示されません」等がある

停止動作（必須）：
- 検知した時点で操作を停止し、その画面を保持する
- 次の「人間向け手順」を表示して終了する（続行しない）

人間向け手順（固定）：
1. 表示されているシークレットを手動でコピーしてください
2. ローカル環境の設定ファイル `backend/.env` を開いてください
3. `DATABASE_URL=` の値に貼り付けて保存してください
4. 管理画面は閉じるか、そのままにしてください（追加操作は不要です）
5. Chat に戻り「進めて」と入力してください

---

## 0. 事前確認（どこから取得するか）

次の選択肢で進める。

* A案：Railway の環境変数から取得【おすすめ】
  - 理由：本リポジトリの記録上、本番Railwayプロジェクト/サービスが同定済みで、最短で到達できるため
* B案：Supabase の接続情報から取得

この手順書は **A案（Railway）** を実施する。
※ もしRailwayが使えない/ログインできない場合は、ここで停止し、どの画面で止まったかだけ報告する（シークレットは報告しない）。

---

## 1. Railwayで DATABASE_URL の場所まで移動（A案）

1) ブラウザで Railway を開く（ログインが必要ならログインする）
2) プロジェクト一覧から、次を開く：
   - プロジェクト名：`respectful-embrace`
3) サービス一覧から、次を開く：
   - サービス名：`security-report-system`
4) サービスの設定画面で「環境変数（Variables）」の画面を開く
5) 変数一覧で `DATABASE_URL` を探す（検索欄があれば `DATABASE_URL` で検索する）

ここで `DATABASE_URL` の値が表示/コピー可能な状態になったら、**シークレット検知**としてSEC-01停止手順に従う（上記の固定手順を表示して停止）。

---

## 2. もし `DATABASE_URL` が見つからない場合

この場合は推測で進めない。

1) 「Variables」画面のまま停止する
2) 次の情報だけを報告する（値は報告しない）：
   - `DATABASE_URL` というキーが存在するか（Yes/No）
   - DB系のサービス（Postgres等）がRailway側に表示されているか（Yes/No）
