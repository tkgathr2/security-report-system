# Claude Code への指示：CSVの文字化け修正（CP932/Shift_JIS → UTF-8）

## 目的

`c:\Users\takag\Downloads\社長に送るものスタッフ一覧 (3).csv` が文字化けしているため、**元ファイルは変更せず**、UTF-8版のCSVを作成する。

---

## 前提

- これは「文字コード変換」の作業であり、アプリ実装ではない
- **元ファイルを上書きしない**（変換後は別ファイル名で保存）

---

## 指示（そのままコピーして実行）

```
# 1) 入力/出力パス（元ファイルは残す）
$in  = "C:\Users\takag\Downloads\社長に送るものスタッフ一覧 (3).csv"
$out = "C:\Users\takag\Downloads\社長に送るものスタッフ一覧 (3)_utf8.csv"

# 2) まず CP932 として読み、UTF-8(BOMなし)で書き出す
#    ※ WindowsのShift_JIS系は多くの場合 CP932 で正しく復元できます
$bytes = [System.IO.File]::ReadAllBytes($in)
$text  = [System.Text.Encoding]::GetEncoding(932).GetString($bytes)
[System.IO.File]::WriteAllText($out, $text, (New-Object System.Text.UTF8Encoding($false)))

# 3) 変換結果の先頭数行を表示して目視確認（漢字/かなが読めること）
Get-Content -Path $out -TotalCount 5
```

---

## 完了条件

- `..._utf8.csv` を開いたとき、氏名・フリガナが**文字化けせずに読める**

---

## もし直らない場合（次の一手）

CP932ではなくUTF-8(BOM付き)で保存したい/ツール都合で必要な場合：

```
$in  = "C:\Users\takag\Downloads\社長に送るものスタッフ一覧 (3).csv"
$out = "C:\Users\takag\Downloads\社長に送るものスタッフ一覧 (3)_utf8_bom.csv"

$bytes = [System.IO.File]::ReadAllBytes($in)
$text  = [System.Text.Encoding]::GetEncoding(932).GetString($bytes)
[System.IO.File]::WriteAllText($out, $text, [System.Text.Encoding]::UTF8)  # BOM付き

Get-Content -Path $out -TotalCount 5
```

それでも読めない場合は、元の出力元（Excel / Googleスプレッドシート等）と、変換後先頭5行の表示結果を共有してください（原因の候補を絞ります）。
