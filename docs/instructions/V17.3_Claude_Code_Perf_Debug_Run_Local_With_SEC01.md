## V0.4 V17.2の計測ログの安全化（クラッシュ防止）

背景（事実）：
- V17.2の差分では `admin.ts` に `__t0_adminProjects` の参照があり、**定義漏れ**の可能性がある（このままだと `/api/admin/projects` で例外になり得る）。
- Node環境によっては `fetch` が未定義の場合があり、計測ログが原因で例外になり得る。

対応（最小）：

### 1) `backend/src/routes/admin.ts`

`router.get('/projects', requireAdmin, async ...` の関数先頭（tryの直後あたり）に以下を追加：
- `const __t0_adminProjects = Date.now();`

さらに、このファイル内の計測ログ送信は「fetchが存在する時だけ実行」に置き換える：
- 置換前：`fetch('http://127.0.0.1:7253/ingest/...',{...}).catch(()=>{});`
- 置換後（1行のまま）：`globalThis.fetch ? globalThis.fetch('http://127.0.0.1:7253/ingest/...',{...}).catch(()=>{}) : undefined;`

※ `admin.ts` の計測ログ送信箇所すべて同様に置換。
