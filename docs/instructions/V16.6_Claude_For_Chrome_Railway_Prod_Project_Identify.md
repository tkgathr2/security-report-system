これは Claude For Chrome への指示です。

目的：
- 本番URL `https://security-report-system-production-926e.up.railway.app/` が、Railwayのどの「プロジェクト / サービス」に紐づいているかを **事実だけで確定**する。
- 以後の監査ログ確認（SQL）を、確定したプロジェクトのPostgresで実施できるようにする。

背景（矛盾の解消が必要）：
- docsには `respectful-embrace` と `zippy-strength` の両方が「本番」として登場しており、文書だけでは確定できない。
- Railway上の「Domains（ドメイン）」一致で確定する。

注意（SEC-01）：
- この工程ではシークレット情報（ログイン情報、接続情報）が必要になる可能性があります。自動入力は行いません。SEC-01 で停止します。
- `DATABASE_URL` 等の接続文字列やシークレット値は、コピー/貼り付け/チャット共有しないでください。
