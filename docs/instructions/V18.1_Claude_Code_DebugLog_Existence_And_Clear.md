# Claude Code：debug.log の存在確認とクリア（Run2再現前）V18.1

これは Claude Code への指示です。

目的：
- `C:\Users\takag\00_dev\security-report-system\.cursor\debug.log` が「存在する/しない」を事実で確認する
- 存在する場合は **削除または空にして**、次のフロント再現ログが混ざらない状態にする

注意：
- シークレットは表示しない
- `debug.log` は計測ログ送信後に自動生成されるため、無い場合がある（その場合はOK）

---

## V0.1 存在確認（隠しファイルも含めて）

```powershell
cd C:\Users\takag\00_dev\security-report-system
Write-Output "=== list .cursor (force) ==="
Get-ChildItem -Force .\.cursor | Format-Table Name,Length,Attributes,LastWriteTime
Write-Output "=== test path ==="
Test-Path .\.cursor\debug.log
```

---

## V0.2 クリア（存在する場合のみ）

### A) 削除できる場合（推奨）

```powershell
if (Test-Path .\.cursor\debug.log) { Remove-Item -Force .\.cursor\debug.log }
Test-Path .\.cursor\debug.log
```

### B) 削除がブロックされる場合（代替：空にする）

```powershell
if (Test-Path .\.cursor\debug.log) { Set-Content -Path .\.cursor\debug.log -Value '' -Encoding utf8 }
Get-Item -Force .\.cursor\debug.log | Format-List FullName,Length,Attributes,LastWriteTime
```

完了条件：
- `debug.log` が存在しない、または 0 bytes 相当になっている
