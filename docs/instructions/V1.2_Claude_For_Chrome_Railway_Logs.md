# Claude For Chrome への指示：Railway Logs 確認（v71 - state競合修正後）

## 目的

`state: true` を `state: false` に変更した修正がデプロイされた後、verify 関数に到達するか確認する。

---

## 前提条件

- Railway ダッシュボードにログイン済みであること
- プロジェクト: `respectful-embrace`
- サービス: `security-report-system`
- **重要**: デプロイ完了を待つこと（約2-3分）

---

## 指示（そのままコピーして実行）

```
以下の手順を順番に実行してください。

【手順1】Railway ダッシュボードを開く
- URL: https://railway.app/dashboard

【手順2】プロジェクト「respectful-embrace」→ サービス「security-report-system」を開く

【手順3】デプロイ状況を確認
- 「Deployments」タブで最新デプロイが「Success」になるまで待つ

【手順4】起動時ログを確認（デプロイ完了直後）
- Logs タブを開く
- 「[Startup Debug]」で検索
- 以下のログを記録：
  - [Startup Debug] GOOGLE_REDIRECT_URL: （この値）

【手順5】本番URLで OAuth ログインを実行
- URL: https://security-report-system-production-926e.up.railway.app/
- 「Googleでログイン」をクリック
- Google 認証を完了

【手順6】Logs で以下を検索・記録

最重要確認ログ：
- [OAuth Debug] ===== VERIFY FUNCTION ENTERED ===== ← これが出力されるか？

その他のログ：
- [Callback Debug] passport.authenticate callback entered
- [Callback Debug] err: 
- [Callback Debug] user: 
- [OAuth Debug] Google profile email:
- [OAuth Debug] Database query result rows:

【手順7】結果を報告
- 「VERIFY FUNCTION ENTERED」が出力されたかどうかを最優先で報告
- ログイン成功/失敗の結果も報告

【注意】
- シークレット情報（トークン、パスワード等）は報告しないでください
```

---

## 期待される結果

### 成功パターン（verify関数に到達）

```
[Startup Debug] GOOGLE_REDIRECT_URL: https://...railway.app/api/admin/auth/google/callback
[OAuth Debug] ===== VERIFY FUNCTION ENTERED =====
[OAuth Debug] Google profile email: atsuhiro@takagi.bz
[OAuth Debug] Database query result rows: 1
[OAuth Debug] Login successful for: atsuhiro@takagi.bz
```

### 失敗パターン（まだ到達しない）

```
[Callback Debug] passport.authenticate callback entered
[Callback Debug] err: null
[Callback Debug] user: false
[OAuth Debug] ===== VERIFY FUNCTION ENTERED ===== ← これがない場合は別の問題
```

---

## 結果による次のアクション

| 結果 | 原因 | 次のアクション |
|------|------|----------------|
| VERIFY FUNCTION ENTERED が出力 + ログイン成功 | **修正完了** | デバッグログ削除 |
| VERIFY FUNCTION ENTERED が出力 + rows=0 | **DB照合失敗** | メールアドレス確認 |
| VERIFY FUNCTION ENTERED が出力されない | **別の原因** | REDIRECT_URL 確認 |
