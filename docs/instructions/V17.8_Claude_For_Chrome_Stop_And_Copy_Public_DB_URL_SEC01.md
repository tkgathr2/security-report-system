# Claude For Chrome：Postgres Public Network 接続文字列の手動コピー（SEC-01停止）V17.8

これは Claude For Chrome への指示です。

目的：
- Railwayの「Connect to Postgres」モーダル（Public Network）で、ローカルから接続可能な接続文字列を **人間が手動でコピー**し、`backend/.env` に投入できる状態にする。

回答言語：
- 日本語で答えてください

重要（SEC-01）：
「この工程ではシークレット情報が必要になる可能性があります。自動入力は行いません。SEC-01 で停止します。」

禁止事項（厳守）：
- 接続文字列（`postgresql://`）やパスワードを、チャット本文/メモ/ログ/ファイルに書く
- その値をコピーして貼り付ける操作を Claude For Chrome が行う
- 値を読み上げる、要約する

停止条件（シークレット検知）：
- `Connection URL` に `postgresql://` が表示されている（伏字でも可）

---

## 手順（いま見えている画面から）

1) 画面は「Connect to Postgres」モーダルのまま維持する（閉じない）

2) `Connection URL` 行の右側にある **コピー（クリップボード）アイコン** をクリックする  
※ `show` を押して値を可視化する必要はありません（見えないままコピーでOK）。

3) ローカルPCで `C:\\Users\\takag\\00_dev\\security-report-system\\backend\\.env` を開く  
   - まだ無ければ新規作成する

4) `.env` に次の行を作り、`=` の右側へ **手動で貼り付けて保存**する（値はここに書かない）
   - `DATABASE_URL=（ここに貼り付け）`

5) ここで作業を止める（SEC-01）。  
   - 以後は Claude Code 側で `docs/instructions/V17.3_Claude_Code_Perf_Debug_Run_Local_With_SEC01.md` の V0.4 以降を実行して、ローカル起動→計測→30秒再現へ進む。

完了条件：
- `backend/.env` に `DATABASE_URL` が設定されている（値は報告しない）
- 接続文字列をチャットに貼らない
