# Claude For Chrome への指示：Railway Logs から OAuth デバッグログを取得

## 目的

本番環境で発生している「Google OAuth ログイン後 403 FORBIDDEN」問題の原因を特定するため、Railway Logs から `[OAuth Debug]` ログを抽出する。

---

## 前提条件

- Railway ダッシュボードにログイン済みであること
- プロジェクト: `respectful-embrace`
- サービス: `security-report-system`

---

## 指示（そのままコピーして実行）

```
以下の手順を順番に実行してください。

【手順1】Railway ダッシュボードを開く
- URL: https://railway.app/dashboard
- ログイン済みでなければログインする

【手順2】プロジェクトを開く
- プロジェクト名「respectful-embrace」をクリック

【手順3】サービスを開く
- サービス名「security-report-system」をクリック

【手順4】Logs（ログ）タブを開く
- 画面上部または左側のナビゲーションから「Logs」または「Deployments」→ 該当デプロイの「View Logs」をクリック

【手順5】ログをフィルタリング
- ログ検索欄があれば「[OAuth Debug]」で検索
- 検索欄がなければ、ログをスクロールして「[OAuth Debug]」を含む行を探す

【手順6】以下の4つのログ行を探して、値を記録する
1. [OAuth Debug] Google profile email: （この後ろの値）
2. [OAuth Debug] All emails from profile: （この後ろのJSON配列）
3. [OAuth Debug] Database query result rows: （この後ろの数値）
4. [OAuth Debug] Database query result: （この後ろのJSON配列）

【手順7】追加で以下のログがあれば記録する
- [OAuth Debug] Email not found in admin_allowlist
- [OAuth Debug] Admin is not active
- [OAuth Debug] Login successful for:

【手順8】結果を報告
- 上記のログが見つかった場合、その内容をチャットにコピー＆ペーストで報告してください
- ログが見つからない場合は「該当ログなし」と報告してください

【注意】
- シークレット情報（トークン、パスワード等）は報告しないでください
- メールアドレスは報告して問題ありません（原因特定に必要）
```

---

## 期待する報告形式

```
【Railway Logs 確認結果】

[OAuth Debug] Google profile email: xxxxxxx@example.com
[OAuth Debug] All emails from profile: [{"value":"xxxxxxx@example.com","verified":true}]
[OAuth Debug] Database query result rows: 0
[OAuth Debug] Database query result: []

追加ログ:
- [OAuth Debug] Email not found in admin_allowlist ← あり/なし
```

---

## この情報で確定できること

| ログの状態 | 原因 |
|-----------|------|
| email が `atsuhiro@takagi.bz` と異なる | **A: Googleアカウント違い** |
| rows: 0 | **B: DB照合失敗** |
| rows: 1 かつ `is_active: false` | **C: 無効化されている** |
| rows: 1 かつ `is_active: true` だが Login successful がない | **別の問題** |
