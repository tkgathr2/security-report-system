## V0.2 計測ログの追加（内訳タイミング）

対象：`router.get('/projects', requireAdmin, async (req, res) => { ... })`

### 1) handler冒頭：全体タイマ（既存が無ければ）

tryブロックの先頭付近に以下を追加（既に同等があれば重複させない）：

```ts
// #region agent log
const __t0_adminProjects = Date.now();
// #endregion
```

### 2) projectsクエリの所要時間を計測

`const result = await pool.query(query, params);` の直前に：

```ts
// #region agent log
const __t0_projectsQuery = Date.now();
// #endregion
```

`const result = await pool.query(...)` の直後に、所要時間ログを追加：

```ts
// #region agent log
globalThis.fetch ? globalThis.fetch('http://127.0.0.1:7253/ingest/f7e4555a-6639-4502-b86d-deba90e7ea4b',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({runId:'pre-fix',hypothesisId:'B2',location:'backend/src/routes/admin.ts:/admin/projects:projects-query-ms',message:'projects query timing',data:{projectsQueryMs:Date.now()-__t0_projectsQuery,projectsRows:result.rows.length},timestamp:Date.now()})}).catch(()=>{}) : undefined;
// #endregion
```

### 3) castsクエリの所要時間を計測（projectIds.length > 0 の分岐内）

`const castsResult = await pool.query(...);` の直前に：

```ts
// #region agent log
const __t0_castsQuery = Date.now();
// #endregion
```

`castsResult` の直後に：

```ts
// #region agent log
globalThis.fetch ? globalThis.fetch('http://127.0.0.1:7253/ingest/f7e4555a-6639-4502-b86d-deba90e7ea4b',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({runId:'pre-fix',hypothesisId:'B2',location:'backend/src/routes/admin.ts:/admin/projects:casts-query-ms',message:'casts query timing',data:{castsQueryMs:Date.now()-__t0_castsQuery,projectIdsLen:projectIds.length,castsRows:castsResult.rows.length},timestamp:Date.now()})}).catch(()=>{}) : undefined;
// #endregion
```

注意：
- `globalThis.fetch ? ... : undefined;` の形にして、Node環境で fetch が無い場合にクラッシュしないようにする。
- `data` には件数とmsのみ（案件名等は絶対に入れない）
