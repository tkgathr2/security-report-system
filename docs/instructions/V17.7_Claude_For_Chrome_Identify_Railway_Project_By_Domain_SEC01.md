# Claude For Chrome：公開URL `security-report.up.railway.app` からRailwayのプロジェクト/サービス同定（SEC-01）V17.7

これは Claude For Chrome への指示です。

目的：
- 公開URL `https://security-report.up.railway.app/` が、Railway上の **どのプロジェクト/サービス/環境** に紐づくかを「事実だけ」で確定する。
- その上で、同じプロジェクト内のPostgres（DB）サービスへ到達し、Public Networking の接続文字列の「場所」まで案内できる状態にする。

回答言語：
- 日本語で答えてください

重要（SEC-01）：
「この工程ではシークレット情報が必要になる可能性があります。自動入力は行いません。SEC-01 で停止します。」

禁止事項（厳守）：
- `DATABASE_URL` や `postgresql://` などの接続文字列（シークレット）をチャット本文/メモ/ログ/ファイルに書く
- シークレット値をコピーする、読み上げる、要約する
- Public Networking の有効化など「設定変更」を勝手に実行する

シークレット検知・停止条件：
- `postgresql://` が表示された
- Password / Connection string / URI / URL、コピーアイコン、伏字などがある

停止動作（必須）：
- 検知した瞬間に操作を停止し、その画面を保持する
- 下記「人間向け手順」を表示して終了する（続行しない）

人間向け手順（固定）：
1. 表示されているシークレットを手動でコピーしてください
2. ローカル環境の `backend/.env` を開いてください
3. `DATABASE_URL=` の値に貼り付けて保存してください
4. Chat に戻り「進めて」と入力してください

---

## 1) 公開URLの稼働確認（事実のみ）

1. `https://security-report.up.railway.app/health` を開く
2. `{ "ok": true }` が返ることを確認する（画面表示だけで良い）

---

## 2) Railwayでドメイン紐づけを探す（プロジェクト→サービス→Domains）

1. Railway を開く（ログインが必要ならログイン）
2. プロジェクト一覧を開く
3. まず **既知の候補プロジェクト** を順に開く：
   - `respectful-embrace`
   - （もし存在すれば）`zippy-strength`
4. 各プロジェクトで、サービス一覧から「Webアプリ（Node/Express）」と思われるサービスを開く
5. サービスの `Settings` / `Domains`（名称が近いもの）を開く
6. ドメイン一覧に `security-report.up.railway.app` が存在するかを確認する

存在した場合：
- そのサービス名と、プロジェクト名を **値を含めず** に記録して終了する（このmd内では報告不要。Chatに戻って「進めて」だけ入力する）

見つからない場合：
- 次へ進む

---

## 3) 見つからない場合の探索（プロジェクト横断検索）

Railway UI に検索機能（ドメインやサービス名検索）があれば、それを使って `security-report` で検索する。

見つかったサービスを開き、Domainsで `security-report.up.railway.app` を確認する。

---

## 4) 同定後：DBサービスへ到達（Public Networking の場所まで）

同定できたプロジェクト内で、Postgres/Database サービスを開く。

次のタブ/メニューを探して開く（表記揺れOK）：
- `Connect` / `Connection` / `Connections`
- `Networking` / `Public Networking`

ここで `postgresql://` の公開接続文字列が表示されたら、**シークレット検知**としてSEC-01停止（固定手順を表示して終了）。

Public Networking が未有効で有効化トグルが見つかった場合：
- 勝手に有効化しない
- その画面で停止し、「有効化トグルがある（Yes/No）」「既に有効化済み表示がある（Yes/No）」だけを報告して終了（値は報告しない）
