# Claude For Chrome：SupabaseのSQL Editorでスタッフ取込の監査ログを確認する

これは Claude For Chrome への指示です。

目的：
- `staff_master` が既に登録済みに見えるため、再インポートせずに「スタッフCSVインポート（staff_import）が実行済みか」をDB監査ログで確定する。
- 監査ログと件数が取れれば、次の一手（再インポート要否）がYes/Noで確定する。

注意（SEC-01）：
- この工程ではシークレット情報（ログイン情報）が必要になる可能性があります。自動入力は行いません。SEC-01 で停止します。

---

## V16.4-0 Supabaseへ移動（ログインが必要ならSEC-01で停止）
1) Supabaseのダッシュボードを開く
2) ログイン画面が出たら **そこで停止**（自動入力しない）
3) ユーザー（高木）が手動でログインする
4) ログイン完了後、作業を再開する

## V16.4-1 対象プロジェクトを開く
1) `security-report-system` のDB（本番に紐づくプロジェクト）を選ぶ
2) 左メニューから `SQL Editor`（または `SQL`）を開く

---

## V16.4-2 監査ログ（staff_import / staff_auto_add）を確認
1) 新しいクエリを作成
2) 次のSQLを貼り付けて実行

```sql
SELECT created_at, admin_email, action, target_type, payload_json
FROM admin_audit_logs
WHERE action IN ('staff_import', 'staff_auto_add')
ORDER BY created_at DESC
LIMIT 20;
```

3) 結果から次をこのチャットに報告（値の貼り付けは必要箇所のみでOK）：
- `staff_import` が存在するか（Yes/No）
- 存在する場合：created_at / admin_email / payload_jsonの要点（file_name, inserted, updated, skipped）
- `staff_auto_add` が存在するか（Yes/No）

---

## V16.4-3 staff_master の件数と当日追加分の確認
次のSQLを順に実行し、結果（数値）をこのチャットに報告してください。

### 総件数
```sql
SELECT COUNT(*) AS total_staff FROM staff_master;
```

### 当日追加件数
```sql
SELECT COUNT(*) AS created_today
FROM staff_master
WHERE created_at::date = CURRENT_DATE;
```

### 直近10件（必要なら）
```sql
SELECT display_name_kanji, display_name_kana, created_at, created_by
FROM staff_master
ORDER BY created_at DESC
LIMIT 10;
```
