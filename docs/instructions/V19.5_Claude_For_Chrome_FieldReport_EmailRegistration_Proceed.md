# Claude For Chrome：報告書入力「メールアドレス登録」画面から再開して次へ進む V19.5

これは Claude For Chrome への指示です。

回答言語：日本語で答えてください。

目的：
- 本番の「メールアドレス登録」画面（`FieldReport.tsx`）から、登録処理を完了させて次画面へ進む。

禁止事項：
- メールアドレスなど個人情報をチャットに貼らない
- Cookie / トークン等のシークレットをチャットに貼らない

対象URL（本番）：
- `https://security-report.up.railway.app/`（ドメイン確認用）
- ※ 実作業は「すでに開いているメールアドレス登録画面」のタブから開始してよい

期待する画面遷移（事実）：
- 「登録して報告書を作成」ボタン押下
  - `POST /api/auth/login`（401なら `POST /api/auth/register`）
  - 成功すると `pageState` が `name_selection` または `form` に変わり、画面が切り替わる

## V0.1 画面の確認
1. すでに開いているタブで、見出しが **「メールアドレス登録」** であることを確認する
2. ボタンが **「登録して報告書を作成」** であることを確認する

## V0.2 登録して次へ進む（本番）
1. ユーザーに、メールアドレス入力欄へメールアドレスを **手動入力** してもらう（Claudeは値を読み上げ/転記しない）
2. 「登録して報告書を作成」をクリック
3. 期待：
   - 「お名前を選択してください」画面に遷移する、または
   - 報告書フォーム画面に遷移する

---

## V0.3 失敗時の切り分け（証拠収集して停止）
遷移せず「登録中...」のまま等で進まない場合のみ実施。

1. DevTools を開く → Network
2. 直後に発生したリクエストのうち、以下を探す（値の中身は貼らない、ステータスとパスだけ）
   - `POST /api/auth/login`
   - `POST /api/auth/register`
3. それぞれについて、次だけ日本語で報告する：
   - どちらが呼ばれたか（login / register / 両方）
   - HTTPステータス（例：200 / 400 / 401 / 500）
   - レスポンスの `message` が表示されていれば **文言だけ**（メール等は伏せる）
4. その時点で操作を止め、画面を保持する（追加操作しない）

完了条件：
- 次画面（名前選択 or フォーム）に進めた、または
- 失敗時に上記の Network 証拠（呼ばれたパスとステータス、必要ならmessage）を報告できた
