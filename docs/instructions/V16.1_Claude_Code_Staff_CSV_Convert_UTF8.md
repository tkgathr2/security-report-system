# Claude Code：スタッフCSVをUTF-8（氏名/フリガナ2列）に変換する

これは Claude Code への指示です。

目的：
- `C:\Users\takag\Downloads\社長に送るものスタッフ一覧 (3).csv` は現状、バックエンドの取込処理がUTF-8前提でヘッダー「氏名」「フリガナ」を探すため、そのままではヘッダー判定に失敗する。
- 取込できる形（UTF-8、BOMあり可、ヘッダーに「氏名」「フリガナ」を含む）へ変換して、インポート用ファイルを作る。

前提：
- 変換後CSVはコミットしない（ローカルのDownloadsに置く）。
- 変換元CSVの列は多いが、先頭2列を「氏名」「フリガナ」として扱い、残りは捨てる（まず事実として取り込める形を作る）。

---

## V16.1-0 変換の実行

PowerShellで以下をそのまま実行してください。

```powershell
cd C:\Users\takag\00_dev\security-report-system

$src = 'C:\Users\takag\Downloads\社長に送るものスタッフ一覧 (3).csv'
$dst = 'C:\Users\takag\Downloads\社長に送るものスタッフ一覧 (3)_staff_import_utf8.csv'

@"
import csv

src = r"""$src"""
dst = r"""$dst"""

def try_read(enc):
    with open(src, "r", encoding=enc, newline="") as f:
        return list(csv.reader(f))

rows = None
used_enc = None
for enc in ["cp932", "shift_jis", "utf-8-sig", "utf-8"]:
    try:
        rows = try_read(enc)
        used_enc = enc
        break
    except Exception:
        pass

if not rows:
    raise SystemExit("failed_to_read_csv")

# 先頭2列のみを抽出（列が足りない行は空で埋める）
out = [["氏名", "フリガナ"]]
for r in rows[1:]:
    if not r:
        continue
    name = (r[0] if len(r) > 0 else "").strip()
    kana = (r[1] if len(r) > 1 else "").strip()
    if not name and not kana:
        continue
    out.append([name, kana])

with open(dst, "w", encoding="utf-8-sig", newline="") as f:
    csv.writer(f).writerows(out)

print("READ_ENCODING", used_enc)
print("WROTE", dst)
print("ROWS", len(out) - 1)
print("HEAD", out[0])
print("SAMPLE1", out[1] if len(out) > 1 else None)
"@ | Set-Content -Encoding UTF8 -Path .\_tmp_convert_staff_csv.py

python .\_tmp_convert_staff_csv.py
```
