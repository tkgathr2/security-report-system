# Claude For Chrome：Railway「Public Networking」DB接続URLの場所まで案内（SEC-01停止）V17.5

これは Claude For Chrome への指示です。

目的：
- ローカルPCから接続可能な **Railwayの公開DB接続URL**（`railway.app` 側）を取得できる「場所」まで案内する。
- 取得後はSEC-01で停止し、**人間が手動でコピー→`backend/.env` に貼り付け**する。

回答言語：
- 日本語で答えてください

重要（SEC-01）：
「この工程ではシークレット情報が必要になる可能性があります。自動入力は行いません。SEC-01 で停止します。」

禁止事項（厳守）：
- 接続URL（ユーザー名/パスワード含む）をチャット本文/メモ/ログ/ファイルに書く
- 接続URLをコピーする、読み上げる、要約する
- 接続URLが表示された後に、勝手に別画面へ遷移する

シークレット検知・停止条件：
- `postgresql://` で始まる接続文字列が表示される
- Password/Connection string/URI/URL、コピーアイコン、伏字等がある

停止動作（必須）：
- 検知した時点で操作を停止し、その画面を保持する
- 下記「人間向け手順」を表示して終了する（続行しない）

人間向け手順（固定）：
1. 画面に表示された **Public Networking** の接続文字列（`railway.app` 側）を手動でコピーしてください
2. ローカルの `backend/.env` を開き、`DATABASE_URL=` の値に貼り付けて保存してください
3. `backend/.env` を保存したら、ブラウザは閉じるかそのままでOKです
4. Chat に戻り「進めて」と入力してください

---

## 手順（Railway）

前提（既知情報）：
- Railwayプロジェクト：`respectful-embrace`
- Railwayサービス：`security-report-system`

1) Railway を開く（ログインが必要ならログイン）
2) プロジェクト一覧から `respectful-embrace` を開く
3) 画面内で **PostgreSQL（DB）** のサービス（例：Postgres/Database 等）を探して開く
   - 見つからない場合：プロジェクト内のサービス一覧を下まで確認し、それでも無ければそこで停止して状況だけ報告（値は報告しない）
4) DBサービスの画面で、接続情報のセクションを探す
5) 「Networking」や「Public Networking」のタブ/セクションを開く
6) `postgresql://` の接続文字列（公開ホストが `railway.app` 側のもの）が表示されたら、**シークレット検知**としてSEC-01停止手順に従う

---

## もし `railway.app` 側の接続文字列が見つからない場合

推測で進めない。

1) 「Networking / Public Networking」らしき画面で停止する
2) 次の情報だけを報告する（値は報告しない）：
   - Public Networking を有効化するトグル/ボタンがあるか（Yes/No）
   - `railway.internal` 以外のホスト名が表示される箇所があるか（Yes/No）
