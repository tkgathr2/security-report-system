# Claude For Chrome への指示：Railway Logs から OAuth デバッグログを取得（v2）

## 目的

新しいデバッグログ（v70）がデプロイされた後、Railway Logs から `[Callback Debug]` ログを抽出し、403 問題の原因を特定する。

---

## 前提条件

- Railway ダッシュボードにログイン済みであること
- プロジェクト: `respectful-embrace`
- サービス: `security-report-system`
- **重要**: デプロイ完了を待つこと（約2-3分）

---

## 指示（そのままコピーして実行）

```
以下の手順を順番に実行してください。

【手順1】Railway ダッシュボードを開く
- URL: https://railway.app/dashboard
- ログイン済みでなければログインする

【手順2】プロジェクトを開く
- プロジェクト名「respectful-embrace」をクリック

【手順3】サービスを開く
- サービス名「security-report-system」をクリック

【手順4】デプロイ状況を確認
- 「Deployments」タブを開く
- 最新のデプロイが「Success」になっていることを確認
- まだ「Building」や「Deploying」の場合は完了を待つ

【手順5】本番URLで OAuth ログインを実行して 403 を再現
- URL: https://security-report-system-production-926e.up.railway.app/
- 「Googleでログイン」をクリック
- Google 認証を完了
- 403 エラーが表示されることを確認

【手順6】Logs（ログ）タブを開く
- サービス詳細画面から「Logs」タブをクリック
- または最新デプロイの「View Logs」をクリック

【手順7】ログをフィルタリング
- ログ検索欄で「[Callback Debug]」を検索
- 見つからない場合は「Callback」だけで検索

【手順8】以下のログ行を探して、値を記録する

必須確認ログ（新規追加分）：
1. [Callback Debug] Entered /google/callback endpoint
2. [Callback Debug] Query params: （この後ろのJSON）
3. [Callback Debug] Session oauthState: （この後ろの値）
4. [Callback Debug] State validation PASSED または FAILED
5. [Callback Debug] passport.authenticate callback entered
6. [Callback Debug] err: （この後ろの値）
7. [Callback Debug] user: （この後ろの値）
8. [Callback Debug] Returning 403 - user is false/undefined

既存ログ（OAuth Debug）：
9. [OAuth Debug] Google profile email: （この後ろの値）
10. [OAuth Debug] Database query result rows: （この後ろの数値）

【手順9】結果を報告
- 上記のログが見つかった場合、その内容をチャットにコピー＆ペーストで報告してください
- 特に「State validation」の結果と「err/user」の値が重要です

【注意】
- シークレット情報（トークン、パスワード等）は報告しないでください
- メールアドレスは報告して問題ありません（原因特定に必要）
```

---

## 期待する報告形式

```
【Railway Logs 確認結果】

[Callback Debug] Entered /google/callback endpoint
[Callback Debug] Query params: {"code":"xxx","state":"xxx"}
[Callback Debug] Session oauthState: xxxxx
[Callback Debug] State validation PASSED
[Callback Debug] passport.authenticate callback entered
[Callback Debug] err: null
[Callback Debug] user: false
[Callback Debug] Returning 403 - user is false/undefined

[OAuth Debug] Google profile email: xxxxx@example.com
[OAuth Debug] Database query result rows: 0
```

---

## この情報で確定できること

| ログの状態 | 原因 |
|-----------|------|
| `[Callback Debug] Entered` がない | **エンドポイントに到達していない** |
| `State validation FAILED` | **セッション/state の問題** |
| `passport.authenticate callback entered` がない | **passport 内部エラー** |
| `err: [エラー内容]` | **Google API エラー** |
| `user: false` + `[OAuth Debug]` がない | **GoogleStrategy コールバック未到達** |
| `user: false` + `rows: 0` | **DB 照合失敗（メール不一致）** |
| `user: false` + `rows: 1` + `is_active: false` | **管理者が無効化** |
